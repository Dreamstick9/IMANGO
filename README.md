# IMANGO
So this project is a subscription tracker, what it does is that in that you can put in the name and the price of any subscription you have, and it will get added below, and the total price will be updated of all your subscriptions, You can also delete any subscription that you do not have now, Also let me clarify one thing is that this project i made was to improve my skills in tailwind css as they were really weak before, and also i got to learn figma, The initial design is made in FIGMA here is the link https://www.figma.com/design/yCuuFF3bK5PN32mCV5lgkq/Untitled?node-id=0-1&t=kCta5CwlewzyQHNh-1 , Also this project is all made by hand, I did not use any AI, as i genuinly wanted to learn these tools, before they are completely taken over by AI.
